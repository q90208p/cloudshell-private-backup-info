隱私權政策

CloudShell-Private-Backup 是供擁有者個人使用、目前仍在驗收中的私人備份應用。以下說明其設計中的資料處理方式。

存取與用途

應用使用完整 Google Drive OAuth 權限，授權能力涵蓋整個 Drive。預定操作限於逐次批准的資料：讀取目的地中繼資料與分享權限、檢查同名檔案、建立新增備份及索引、下載並核對內容。索引包含檔案 ID、來源版本、大小及雜湊。

保存與安全

備份保存於擁有者指定的私人 Google Drive。專用認證與非秘密收據保存於擁有者控制的 Cloud Shell；長期認證採明文檔案，目錄及檔案使用限制性權限，同 UID 或 root 仍可能讀取，不宣稱加密保存。傳輸使用 HTTPS。認證不得加入備份、Git、對話或一般日誌。

資料分享與使用限制

應用不以廣告、出售使用者資料或訓練 AI 模型為目的使用 Google 使用者資料，不主動向其他使用者分享備份。Google 為儲存及認證服務提供者。本應用對 Google API 所取得資訊的使用及轉移遵守 Google API Services User Data Policy，包括 Limited Use 要求。

保留、刪除與撤銷

備份保留期限由擁有者依工作包決定，沒有預設的 Drive 自動刪除排程。本機成果只有在外部保存核對成立且明確獲准後才清理。擁有者可從 Google 帳戶撤銷本應用授權；撤銷不會刪除已保存的備份，刪除本機 token 也不等於撤銷遠端授權。

網站與聯絡

本靜態網站不設追蹤程式、表單或登入功能；GitHub Pages 託管服務可能依其政策處理基本連線紀錄。政策或資料處理方式變更時會更新本頁。非秘密問題可透過 專用 repository 的 Issues聯絡管理者，請勿提供憑證或私人備份。
